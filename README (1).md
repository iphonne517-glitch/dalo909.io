# حاسبة الكهرباء والمياه – السعودية

حاسبة تفاعلية بصفحة HTML واحدة لحساب الفاتورة الشهرية السكنية للكهرباء والمياه بالتعرفة السابقة (حتى 31 ديسمبر 2026) والجديدة (من 1 يناير 2027).

## المزايا
- حساب تدريجي حسب الشرائح مع ضريبة القيمة المضافة 15%
- مقارنة الفاتورة السابقة والجديدة والزيادة الشهرية والسنوية
- تفصيل كل شريحة وشريط يوضح موقع استهلاكك منها
- خيار تضمين الصرف الصحي في المياه
- حاسبة عكسية: كم أستهلك بميزانية معينة؟
- يدعم الوضعين الفاتح والداكن ويعمل على الجوال

## التشغيل
افتح `index.html` في المتصفح مباشرة. لا يحتاج إلى بناء أو تثبيت. الخطوط تُحمَّل من Google Fonts، ويعمل الملف بخطوط النظام عند عدم الاتصال.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. سيظهر الرابط بعد دقائق على الشكل `https://USERNAME.github.io/REPO/`.

## مصدر الأرقام
الأسعار مأخوذة من إنفوجرافيك منشور (WAMD) وليست من جهة رسمية. تحقق منها من الجهة المزودة للخدمة قبل الاعتماد عليها. لا يشمل الحساب الرسوم الثابتة.

### ملاحظة عن المياه
جدول أسعار المياه والصرف في الإنفوجرافيك يعطي ضعف الفاتورة المعروضة في أمثلته. الوضع الافتراضي يطابق الأمثلة، ويمكن التبديل إلى جمع أسعار الجدول مباشرة من خيار «طريقة حساب المياه».

## تعديل الأسعار
الأسعار في أعلى وسم `<script>` داخل `index.html`:

```js
const ELEC  = { old: [0.18, 0.30], new: [0.21, 0.33] }; // ر.س لكل ك.و.س
const ELEC_B = [6000, Infinity];                         // حدود الشرائح
const WB    = [15, 30, 45, Infinity];                    // حدود شرائح المياه (م³)
const WATER = { old: { w: [...], s: [...] }, new: { w: [...], s: [...] } }; // w مياه، s صرف
```
