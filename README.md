# 🐑 مراعي تيماء — متجر لحوم طازجة وذبائح

متجر إلكتروني عربي احترافي، متجاوب بالكامل (RTL)، لبيع اللحوم الطازجة والذبائح — بدون أي إطار عمل أو خطوة بناء: **HTML + CSS + JavaScript** فقط.

## ✨ المميزات

- تصميم عربي RTL بهوية نجدية (نقش السدو، خط Lalezar للعناوين وReadex Pro للنصوص)
- 12 منتجًا في 4 تصنيفات مع فلترة فورية
- اختيار طريقة التقطيع لكل منتج (مفطح، أرباع، مقطع، مفروم...)
- سلة مشتريات كاملة: درج جانبي، تعديل كميات، حساب الإجمالي تلقائيًا
- إتمام الطلب عبر واتساب برسالة تحوي تفاصيل الطلب كاملة
- متجاوب حتى شاشات الجوال الصغيرة، مع قائمة تنقل منسدلة
- دعم إمكانية الوصول: تباين ألوان، تركيز لوحة المفاتيح، `prefers-reduced-motion`

## 📁 هيكل المشروع

```
marai-tayma/
├── index.html          # هيكل الصفحة
├── assets/
│   ├── css/style.css   # كل التنسيقات
│   └── js/app.js       # المنتجات + السلة + التفاعلات
└── README.md
```

## 🚀 التشغيل محليًا

لا يحتاج أي تثبيت — افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
npx serve .
# أو
python3 -m http.server 8000
```

## 🌐 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع الملفات:

```bash
git init
git add .
git commit -m "متجر مراعي تيماء — الإصدار الأول"
git branch -M main
git remote add origin https://github.com/USERNAME/marai-tayma.git
git push -u origin main
```

2. من صفحة المستودع: **Settings ← Pages ← Branch: main / (root) ← Save**
3. سيكون المتجر متاحًا على: `https://USERNAME.github.io/marai-tayma/`
